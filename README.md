A single-file Python script that fixes DRM playback in the
[Helium browser](https://helium.is/) by copying `WidevineCdm` from an
already-installed Chromium browser (Chrome, Edge, or Brave) into Helium's
version directory.

## Why?

Helium ships without the Widevine CDM, so DRM-protected sites like YouTube
and Crunchyroll show errors.  This script copies the CDM from a browser that
already has it.

> **Limitation:** Copying `WidevineCdm` only lets Helium *load* Widevine.
> It does **not** change Helium's browser identity, VMP certification, or
> HDCP support.  Strict services such as Netflix or Amazon Prime Video may
> still refuse to play, because they require an approved browser or output
> protection that no file copy can satisfy.

## Requirements

- Windows 10 / 11
- Python 3.8+ (stdlib only — no `pip install` needed)
- At least one of: **Google Chrome**, **Microsoft Edge**, or **Brave Browser**

## Usage

```
python fix_helium_drm.py [options]
```

| Flag | Description |
|---|---|
| *(no flags)* | Find source, find Helium, copy WidevineCdm |
| `--check` | Detect source/target and report; no changes made |
| `--dry-run` | Show what would be copied; no changes made |
| `--verbose` | Print every path probed during detection |
| `--source-path PATH` | Use a specific `WidevineCdm` directory instead of auto-detect |
| `--helium-path PATH` | Use a specific destination path instead of auto-detect |

### Examples

```powershell
# See what the script would do (safe, read-only)
python fix_helium_drm.py --dry-run --verbose

# Actually apply the fix
python fix_helium_drm.py

# Use a custom source (e.g. if you have Brave in a non-standard location)
python fix_helium_drm.py --source-path "D:\Apps\Brave\Application\1.70.0.0\WidevineCdm"
```

After the script finishes, **restart Helium** for the change to take effect.

## Troubleshooting

### "No WidevineCdm source found"
Install Google Chrome, Microsoft Edge, or Brave, then run the script again.

### "Helium browser not found"
Install Helium from [https://helium.is/](https://helium.is/) and launch it at
least once (so it creates its versioned application directory).

### "Permission denied"
Try running your terminal / PowerShell window as Administrator.  This is
unusual because Helium installs to `%LOCALAPPDATA%` (per-user), but may
happen if your source browser is under `Program Files`.

## How it works

1. Scans for a valid `WidevineCdm` directory in Chrome, Edge, and Brave
   — both the classic *Application* layout and the newer *User Data*
   component-updater layout.
2. Locates the Helium version folder at
   `%LOCALAPPDATA%\imput\Helium\Application\<version>`.
3. Removes any existing `WidevineCdm` in that folder and copies the source
   in its place.
